# Roadmap

JARVIS Dashboard is developed in functional, testable, documented, and committed versions.

## v0.1 — Project Bootstrap

- Create the repository architecture.
- Add professional project documentation.
- Add MIT license.
- Add roadmap and changelog.
- Create dashboard folders.
- Do not implement the interface yet.

## v0.2 — JARVIS Theme

- Create the Home Assistant theme.
- Define CSS variables.
- Document the color palette.
- Add Card-mod foundation where appropriate.

## v0.3 — Command Header

- Add the main header.
- Add logo placement.
- Add clock area.
- Add MQTT connection status.
- Add Codex status summary.

## v0.4 — Current Mission

- Create the primary current mission card.
- Show current task, duration, health, and working state.
- Add subtle breathing animation when Codex is active.

## v0.5 — Real-Time Console

- Add live command output view.
- Support recent activity rendering.
- Keep the interface readable under high-frequency updates.

## v0.6 — Timeline

- Add activity timeline.
- Show task phases, file events, commands, warnings, and errors.

## v0.7 — System Monitoring

- Add system resource cards.
- Track CPU, memory, disk, and process health.

## v0.8 — Docker Monitoring

- Add container status supervision.
- Track running services and image health.

## v0.9 — History

- Add historical mission/session views.
- Provide summaries for previous Codex runs.

## v1.0 — Complete Dashboard

- Deliver the full dashboard experience.
- Provide complete setup documentation.
- Document all dependencies and MQTT topics.
- Prepare the project for broader open source usage.
